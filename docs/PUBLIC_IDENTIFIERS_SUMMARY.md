# Public identifiers

- GitHub repository: https://github.com/hygomez/lightning-mortality-peru
- Software, concept DOI: https://doi.org/10.5281/zenodo.21764485
- Aggregate dataset, concept DOI: https://doi.org/10.5281/zenodo.21764558

**Cite the concept DOIs.** Each of them always resolves to the most recent version
of its deposit, so a citation does not go stale when a revision is archived. Each
deposit has its own concept DOI: the dataset's is not the software's.

Version-specific DOIs are listed in `PUBLICATION_IDENTIFIERS.md`.

Individual-level SINADEF records remain excluded from the public release.
