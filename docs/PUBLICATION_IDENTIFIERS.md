## Concept DOIs — cite these

A concept DOI always resolves to the most recent version of its deposit, so a
citation does not go stale when a revision is archived. **Each deposit has its own
concept DOI: the dataset's is not the software's.**

- Software, all versions: https://doi.org/10.5281/zenodo.21764485
- Aggregate dataset, all versions: https://doi.org/10.5281/zenodo.21764558

## Recommended manuscript statement

Aggregated, non-identifiable data and reproducibility materials supporting the findings of this study are permanently archived in Zenodo at https://doi.org/10.5281/zenodo.21764558. The analytical code is available on GitHub at https://github.com/hygomez/lightning-mortality-peru and archived in Zenodo at https://doi.org/10.5281/zenodo.21764485. Individual-level SINADEF records are not redistributed because they contain sensitive mortality information.
