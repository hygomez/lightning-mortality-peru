# Journal submission checklist

## Scientific files

- [ ] English manuscript uses the selected title.
- [ ] Abstract and keywords are in English.
- [ ] Tables are editable.
- [ ] Figures are in English and at journal-quality resolution.
- [ ] A district-level geospatial map is included or justified.
- [ ] All numbers match `output/tables/results_summary.csv`.
- [ ] The distinction between 593 national and 591 geocoded cases is maintained.

## Research transparency

- [ ] Public GitHub URL inserted.
- [ ] Zenodo DOI inserted.
- [ ] Data-availability statement inserted.
- [ ] Code-availability statement inserted.
- [ ] Exact SINADEF access date and source-file checksum recorded.
- [ ] Exact INEI population source documented.
- [ ] Exact district-boundary source documented.
- [ ] Exact DEM product, version, resolution, and access date documented.
- [ ] NASA LIS/OTD DOI and access date documented.

## Authorship and administration

- [ ] Final author order approved by all authors.
- [ ] Each author satisfies authorship criteria.
- [ ] ORCID values checked.
- [ ] CRediT contributions completed.
- [ ] Corresponding author selected.
- [ ] Ethics/exemption wording approved by the institution.
- [ ] Funding declaration completed.
- [ ] Conflicts-of-interest declaration completed.
- [ ] Cover letter completed.
- [ ] APC funding or waiver strategy confirmed.
